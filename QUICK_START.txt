================================================================================
STEP 1: MONGODB SETUP (Choose One)
================================================================================

OPTION A: MongoDB Atlas (Cloud - RECOMMENDED)
─────────────────────────────────────────────
1. Go to: https://www.mongodb.com/cloud/atlas
2. Create free account
3. Create new cluster
4. Click "Connect" → "Connect your application"
5. Copy connection string:
   mongodb+srv://username:password@cluster.mongodb.net/nordhavn
6. Use this in backend/.env

OPTION B: Local MongoDB
───────────────────────
1. Download: https://www.mongodb.com/try/download/community
2. Install and start MongoDB service
3. Connection string:
   mongodb://localhost:27017/nordhavn

================================================================================
STEP 2: BACKEND SETUP
================================================================================

cd backend

# Create .env file
cp .env.example .env

# Edit .env and add your MongoDB URI:
# MONGODB_URI=your_connection_string_here
# JWT_SECRET=any_random_secret_key_here

# Install dependencies
npm install

# Seed demo data (creates users and 6 shipments)
node seeds/seedData.js

# Start backend server
npm run dev

Expected output:
  MongoDB connected successfully
  Server running on port 5000

================================================================================
STEP 3: FRONTEND SETUP (New Terminal)
================================================================================

cd frontend

# Create .env file
cp .env.example .env

# Install dependencies
npm install

# Start frontend
npm run dev

Expected output:
  ready - started server on 0.0.0.0:3000, url: http://localhost:3000

================================================================================
ADDING A NEW SHIPMENT (Admin Only)
================================================================================

1. Login as admin@test.com
2. Click "Manage Shipments" in sidebar
3. Click "Add New Shipment"
4. Fill form:
   - Shipment ID (e.g., SHP-007)
   - Origin (city name)
   - Destination (city name)
   - Status (dropdown)
   - Risk Score (0-100)
   - Compliance % (0-100)
   - Departure Date
   - Expected Arrival Date
   - Cargo Type
   - Weight (kg)
   - Value ($)
   - Current Location
   - Notes (optional)
5. Click "Add Shipment"
6. New shipment appears instantly on:
   - Dashboard
   - Shipments List
   - Manage Shipments table

================================================================================
DELETING A SHIPMENT (Admin Only)
================================================================================

1. Go to "Manage Shipments"
2. Find shipment in table
3. Click "Delete" button
4. Confirm deletion
5. Shipment removed from all views

================================================================================
DATABASE FIELDS
================================================================================

Each shipment has:
- shipmentId (unique ID like SHP-001)
- origin (starting location)
- destination (final location)
- status (In Transit, At Port, Delayed, Completed)
- riskScore (0-100, affects KPI cards)
- compliancePercentage (0-100, for compliance tracking)
- departureDate (when shipment left)
- expectedArrival (when should arrive)
- cargoType (Electronics, Chemicals, etc.)
- weight (in kilograms)
- value (cargo value in USD)
- currentLocation (current position)
- documents (proof, bills, etc.)
- notes (any special info)
- createdAt, updatedAt (auto-generated timestamps)

================================================================================
TROUBLESHOOTING
================================================================================

BACKEND WON'T START:
  → Check MongoDB connection string in .env
  → Verify MongoDB is running
  → Check if port 5000 is in use

FRONTEND WON'T START:
  → Verify backend is running first
  → Check NEXT_PUBLIC_API_URL in .env
  → Delete node_modules and reinstall

CAN'T LOGIN:
  → Use exact credentials: admin@test.com / password123
  → Check backend is running
  → Check browser console for errors

CAN'T ADD SHIPMENT:
  → Must be logged in as admin
  → Fill all required fields
  → Check backend logs for errors

API ERRORS:
  → Check backend console for connection errors
  → Verify MongoDB is connected
  → Restart backend server
